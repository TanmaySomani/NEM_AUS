# Original exploratory notebooks

These nine notebooks are preserved unchanged as the research history of NEM_AUS. They include duplicated experiments, references to source files not present in the repository, and historical TensorFlow/RNN/LSTM results that are **not reproduced or endorsed** by the rebuilt benchmark.

The supported, executable notebooks are in [`../../notebooks/`](../../notebooks/):

1. `01_data_quality.ipynb` — raw-source preparation, timestamp and integrity checks.
2. `02_market_exploration.ipynb` — market, season, hourly demand/solar and weather exploration.
3. `03_forecasting.ipynb` — rerun training and compare the held-out benchmark and classifier.
4. `04_volatility_and_smoothing.ipynb` — episodes, threshold sensitivity and causal versus retrospective smoothing.

The original file contents are unchanged; only their location has changed. Git history also retains the original root paths. Do not use the archived notebook metrics as the current dashboard’s evaluation.
